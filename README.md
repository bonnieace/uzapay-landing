# UzaPay Landing Page

Original UzaPay landing page for an offline-first POS system for Kenyan businesses.

## Positioning
- Offline-first POS for Kenya
- Sales management
- Inventory and stock management
- Receipts
- Staff and shift workflows
- Mobile + desktop
- Business reporting

The page is intentionally SEO-oriented around natural phrases such as POS system Kenya, point of sale Kenya, offline POS Kenya, retail POS software, inventory management, mobile POS and desktop POS.

The waitlist form is a front-end prototype using localStorage. Connect it to your production email/database endpoint before launch.
